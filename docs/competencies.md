# Learning objectives and competencies

## Disability specialist (DS)

| Code | Description |
|------|-------------|
| DS-01 | Document functional baseline and communication method before disposition |
| DS-02 | Plan reasonable accommodations (AAC visible, re-test after stabilisation, positioning) |
| DS-03 | Coordinate disability-informed care during reversible airway emergencies |

## ICU neuro-critical (ICU)

| Code | Description |
|------|-------------|
| ICU-03 | Appropriate escalation for status dystonicus / neuro-respiratory storm |

## StormCode critical rules

These rules must not be violated in the Noah post-stage-2 scenario:

| Rule ID | Intent |
|---------|--------|
| `do_not_call_event_behavioural` | Do not mislabel neuro-respiratory storm as behavioural |
| `do_not_remove_AAC` | Keep augmentative communication at bedside |
| `do_not_assume_AAC_reliable_during_event` | Re-test intentionality after stabilisation |
| `do_not_activate_ceiling_of_care_for_reversible_airway_emergency` | Full rescue remains appropriate |
| `do_not_allow_infection_control_to_delay_airway_rescue` | Airway rescue takes priority |
| `do_not_restart_pain_button_without_pain_anaesthesia_review` | Pain pathway requires anaesthesia review |
| `do_not_aggressively_reposition_without_airway_spine_control` | Controlled reposition only |

## Rubric bands

Default pass threshold: **70%** normalized across weighted dimensions. Bands: excellent (90%+), proficient (70%+), developing (50%+).
